Getting Started

            
Ads OS works with raw CSV or Excel exports from Google Ads, Meta Ads, and Google Analytics 4. You do not need to clean or format your files - the tool handles messy real-world exports automatically.


            

              
1
Add a client - Go to Settings, enter a client name and currency, click Add. Then select the client from the dropdown in the top bar.

              
2
Set business context - Go to Context, choose a business type, and fill in goals and any campaign notes. This makes all AI output specific to your client.

              
3
Upload and audit - Go to Audit, drop your Google/Meta CSV, click Upload and Analyze. Your first report is ready in under 2 minutes.

              
4
Run Structured Audit - Click Structured Audit in the sidebar, then Run Audit. This runs 50+ automated checks and produces an account health score.

              
5
Check alerts and anomalies - After every upload, KPI alerts fire automatically. Check Anomaly Spotter for statistical deviations against historical baselines.

            


            

              
              
Executive Dashboard - total spend, blended ROAS, revenue trend, and channel split at a glance.

            

          


          
          

            
Audit

            
The Audit page is where you upload data and generate reports. Drop one or more CSV files, let the tool detect and clean them, and click Upload and Analyze.


            
What files to upload

            

              

                
FileRequired?What it adds

                
                  
Google Ads CSVOptional (need at least one)Campaign spend, ROAS, conversions, CTR, CPC, keywords

                  
Meta Ads CSVOptional (need at least one)Campaign spend, purchase ROAS, results, CTR, CPC

                  
Funnel CSVOptionalLeads, MQLs, SQLs, customers - adds CPL and funnel metrics

                  
GA4 Export CSVOptionalSessions, bounce rate, engaged sessions per campaign

                
              

            


            
Auto-detection and cleaning

            
The tool automatically identifies which platform each file belongs to by scanning the first 2KB of headers. It then:

            
    
              
  • Fuzzy-matches column names (handles "Campaign name", "campaign_name", "Campaign Name" as the same column)
    • 
              
  • Strips currency symbols (Rs, $, £) and expands shorthand numbers (1.2K, 2.5L, 1Cr)
    • 
              
  • Removes summary rows (Total, Grand Total)
    • 
              
  • Normalises 12+ date formats including Indian fiscal years and Excel serials
    • 
              
  • Detects data granularity (keyword, ad, ad group, campaign, placement) and aggregates appropriately
    • 
            


            
Column mapping

            
If a column is not auto-detected, click Map Columns before uploading. A modal shows all columns in your file with auto-suggestions. Manually map any unrecognised columns before proceeding.


            
Comparing periods

            
Toggle Compare Periods to upload a previous period alongside the current one. The report will show delta indicators for every metric.


            

              
              
Audit page - drop Google Ads, Meta Ads, Funnel, and GA4 files. Platform is auto-detected.

            

          


          
          

            
Structured Audit

            
Runs 50+ automated checks across 6 categories. Each check returns Pass, Warning, or Fail. The overall account health score is 0-100.


            

              

                
CategoryWhat it checks

                
                  
Tracking FoundationZero-conversion campaigns, conversion value gaps, ROAS data quality

                  
Campaign ArchitectureBudget concentration, campaign count, naming consistency, objective mix

                  
Ad Set ConfigurationLearning phase flags, bid strategy consistency, spend distribution

                  
Creative PerformanceCTR vs platform benchmark, CTR decline trend, creative format diversity

                  
Cost DiagnosticsCPA vs target, ROAS vs target, CPC outliers, wasted spend ratio

                  
Account HealthZero-spend campaigns, ghost campaigns, spend efficiency, top campaign health

                
              

            


            
Campaigns tagged as brand_awareness in the Context page are automatically excluded from ROAS and wasted spend checks. Per-campaign ROAS and CPA targets set in Context override account-level thresholds for each check.


            
Click Run Audit to execute. The AI summary section is generated by Claude and explains the most important issues in plain English. Action items from this run are automatically added to the Action Plan.


            

              
              
Structured Audit - health score ring, per-category bar chart, and prioritised action items.

            

          


          
          

            
Anomaly Spotter

            
Detects statistical deviations in campaign performance against each campaign's own historical baseline. Requires 3+ historical uploads to activate.


            
How it works

            
For each campaign, the tool looks at the last 30 days of uploaded data and builds a median baseline (resistant to single outlier periods). It then compares the latest values against that baseline using these thresholds:

            
    
              
  • CPL spike - cost per lead up more than 30% vs median
    • 
              
  • ROAS drop - ROAS down more than 20% vs median
    • 
              
  • CTR drop - CTR down more than 25% vs median
    • 
              
  • Spend pacing - spend off by more than 15% vs 7-day average
    • 
            


            
Severity levels

            
Critical - deviation is 2x or more the threshold. Warning - 1-2x. Info - near threshold.


            
Managing anomalies

            
Each anomaly has three statuses: Open (active, needs attention), Acknowledged (you have seen it), Resolved (fixed). Use the buttons on each card to update status.


            
Morning Brief

            
Click Morning Brief for a Claude-generated summary of all open anomalies, prioritised by severity. Tells you what to look at first when you start the day.


            

              
              
Anomaly Spotter - Critical and Warning anomalies with campaign context and detection date.

            

          


          
          

            
Revenue Forecast

            
Projects spend, revenue, ROAS, and conversions for the next 7, 30, or 60 days based on all historical uploads. Uses a weighted moving average model with recency bias and seasonality factors.


            
How the model works

            
    
              
  • The most recent period gets 6x the weight of the oldest period in the moving average
    • 
              
  • A trend slope (average change per period) is calculated and added to the projection
    • 
              
  • A seasonality factor compares the target month against the same month in prior years (clamped 0.5x - 2.0x)
    • 
              
  • Needs at least 3 uploads to produce a meaningful forecast
    • 
            


            
Output

            
    
              
  • Projected spend, revenue, ROAS, and conversions for the account
    • 
              
  • Per-campaign projections for the top campaigns by projected spend
    • 
              
  • Trend direction per metric (up / down / flat)
    • 
              
  • Historical chart for the last 6 periods with the projection dotted in
    • 
              
  • Claude narrative - what to expect and 2 concrete actions to take before the period starts
    • 
            


            
Use the 7D / 60D tabs to switch forecast horizon. Click Refresh to re-run the model after a new upload.


            

              
              
Forecast - projected KPIs, historical vs projection chart, and AI narrative with recommended actions.

Budget Agent

            
A two-layer reallocation engine. First pure rule enforcement, then Claude reasoning on top.


            
Budget Rules

            
Set your minimum ROAS floor and maximum CPL ceiling for Google and Meta. Set a Max Budget Shift % to cap how aggressively the agent redistributes budget (default cap is 20% of account total).


            
How it works

            
    
              
  • Layer 1 - Rule enforcement: Identifies every campaign below ROAS floor or above CPL ceiling. Tags underperformers for pause or decrease. Calculates freed budget. Identifies winners (ROAS > floor x 1.5) to receive the shift.
    • 
              
  • Layer 2 - Claude reasoning: Claude receives violations, winners, full metrics, and your business context. Returns per-campaign recommendations (increase / decrease / pause) with confidence scores 0-100, risk flags, and rationale notes.
    • 
            


            
If Claude is unavailable, Layer 1 still runs and produces a rule-based report with clear explanation. Action items are added to the Action Plan automatically.


            

              
              
Budget Agent - set ROAS floors, CPL ceilings, and max budget shift before running the agent.

            

          


          
          

            
Client Context

            
The most important setup step. Context makes all AI output specific to your client instead of generic. Fill this in before running any AI features.


            
What to fill in

            
    
              
  • Business Type - Each type carries implied assumptions injected into Claude prompts. E-commerce adds cart abandonment and retargeting guidance. B2B SaaS adds long sales cycle and lead quality focus.
    • 
              
  • Primary Goal and Target Audience - Plain English description of what you are optimising for and who you are targeting.
    • 
              
  • Average Order Value - E-commerce only. Used to contextualise ROAS expectations.
    • 
              
  • Seasonal Context - E.g. "Diwali is peak season, Oct-Nov see 3x normal spend." Claude uses this to avoid flagging intentional seasonal budget spikes.
    • 
              
  • Campaign Notes - Critical field. Explain any campaigns that look bad on metrics but have a purpose. E.g. "Brand Awareness - Mumbai is top-of-funnel, not expected to convert directly."
    • 
              
  • Budget Constraints - E.g. "Fixed monthly budget Rs 2L, cannot shift more than 20% from Meta."
    • 
              
  • Attribution Model - Tells Claude how to interpret cross-channel ROAS numbers correctly.
    • 
            


            
Campaign Type Tags

            
Tag each campaign with its purpose. Campaigns tagged brand or brand_awareness are automatically excluded from ROAS failure checks, wasted spend calculations, and CPA spike alerts across the entire tool.


            
Per-Campaign Targets

            
Override account-level ROAS floors and CPL ceilings on a per-campaign basis. A Performance Max campaign can have a ROAS target of 3x while a Retargeting campaign has a target of 2x. Structured Audit checks and KPI alerts use these individual targets.


            

              
              
Context - configure business type, goals, campaign tags, and per-campaign targets. Flows into every AI feature.

            

          


          
          

            
AI Copilot

            
Ask questions about your campaigns. The Copilot answers using real data from your most recent upload - metrics, anomalies, action items, trends, and business context.


            
Opening the Copilot

            
Click the blue chat bubble in the bottom-right corner of any screen. The panel slides in. Type a question or tap one of the quick prompts.


            
What it knows

            
    
              
  • All campaign metrics from the latest upload (spend, ROAS, CPA, CTR, CPC, wasted spend)
    • 
              
  • Open anomalies and their severity
    • 
              
  • Pending action items from the Action Plan
    • 
              
  • Historical trend for the last 6 periods
    • 
              
  • Your full business context (goals, brand exclusions, per-campaign targets)
    • 
            


            
Types of questions

            
    
              
  • Data lookups - "Which campaign had the worst ROAS last month?"
    • 
              
  • Strategic - "Should I pause Performance Max or reduce the budget?"
    • 
              
  • Diagnostic - "Why is CTR declining on Brand Search?"
    • 
              
  • Planning - "Where should I move the budget freed from pausing X?"
    • 
            


            
The Copilot can detect when a question warrants running another feature and will suggest triggering the Budget Agent, Narrator, or Forecast inline.

          


          
          

            
History

            
All reports and uploads are stored in History. Use it to view past reports, compare periods, and track metric trends over time.


            
Performance Trend chart

            
Shows spend, ROAS, conversions, CTR, CAC, or CPL across all uploaded periods. Switch metrics using the buttons on the top right. The x-axis uses actual period dates, not upload timestamps.


            
Multi-Period Comparison

            
Tick 2-4 uploads in the comparison row, then click Compare. A side-by-side table shows every campaign metric across the selected periods.


            
Report cards

            
Each card shows the report type (Audit, Narrative, Budget), date, and links to View, Share, PDF, and Delete. View opens the full HTML report. PDF generates a downloadable file.


            
Importing historical data

            
To import past periods, go to Audit and click Import History. Set the Period Label (e.g. "Jan 2026"), Period Start, and Period End dates before uploading. Historical periods appear correctly in all trend charts and anomaly baselines.


            

              
              
History - performance trend chart, multi-period comparison selector, and all saved reports.

            

          


          
          

            
Settings

            
Manage clients, set default budget rules, and configure report branding.


            
Client management

            
Add a new client by entering a name and selecting a currency, then clicking Add. Each client has its own data, context, budget rules, and report history. Switch between clients using the dropdown in the top bar.


            
Budget Rules

            
Set the default account-level minimum ROAS and CPL ceiling for Google and Meta. These are used by the Budget Agent and Structured Audit checks unless overridden by per-campaign targets in Context.


            
Report Branding

            
Add your agency name and logo. These appear in the header of every generated audit report PDF.


            

              
              
Settings - manage clients, set budget rule defaults, and add agency branding to reports.
